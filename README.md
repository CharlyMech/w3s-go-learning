Personal practice repo while working through the [W3Schools Go tutorial](https://www.w3schools.com/go/index.php).

## Contents

Exercises organized by topic, one folder per tutorial section, mirroring the order in the [W3Schools Go tutorial](https://www.w3schools.com/go/index.php):

```
w3s-go-learning/
├── 01-syntax/
│   └── main.go
├── 02-variables/
│   └── main.go
├── 03-functions/
│   └── main.go
└── ...
```

## Requirements

- [Go](https://go.dev/dl/) 1.20+

> Mine is: `go1.27.1`

## Running an exercise

```bash
go run path/to/file.go
```
